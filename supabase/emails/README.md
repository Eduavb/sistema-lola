# E-mails de autenticação (português)

Gerados por `npm run emails`. Cole em Supabase > Authentication > Emails > Templates.

- **Confirm sign up**: arquivo `confirmar-cadastro.html`, assunto: `Confirme seu e-mail na LOLA`
- **Reset password**: arquivo `redefinir-senha.html`, assunto: `Redefina sua senha da LOLA`
- **Invite user**: arquivo `convite.html`, assunto: `Você foi convidada para a LOLA`
- **Magic link**: arquivo `link-magico.html`, assunto: `Seu link de acesso à LOLA`
- **Change email address**: arquivo `alterar-email.html`, assunto: `Confirme seu novo e-mail na LOLA`
